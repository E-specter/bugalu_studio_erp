# RF-03 · Publicar y consultar franjas de sala

**Requerimiento:** El Administrador publica cada semana las franjas de disponibilidad por sala (A, B, C), de duración y cantidad variables. Visitantes y clientes consultan los tramos libres dentro de esas franjas; no existe un calendario libre de salas.
