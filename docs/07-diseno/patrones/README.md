# Patrones de composición

Combinaciones recurrentes de [componentes](../componentes/README.md). Una spec de pantalla elige una estructura y aplica los patrones que le correspondan; si una pantalla necesita una composición nueva que se repetirá, primero se documenta aquí.

| Patrón | Archivo | Cubre |
|---|---|---|
| Estructura de app y navegación | [estructura-app](estructura-app.md) | Landing, acceso, flujo, app; navegación; formato de datos |
| Formularios | [formularios](formularios.md) | Composición, validación, prevención de errores, accesos |
| Tablas y tableros | [tablas-y-tableros](tablas-y-tableros.md) | Directorio, tablero de producción, partidas, densidad |
| Estados del sistema | [estados-sistema](estados-sistema.md) | Vacío, carga, error, éxito, permisos |
| Flujo por pasos | [flujo-por-pasos](flujo-por-pasos.md) | Contratación, reserva, asesoría |
| Audio, versiones y revisión | [audio-y-versiones](audio-y-versiones.md) | Carga, publicación, revisión con comentarios, historial, descarga |
