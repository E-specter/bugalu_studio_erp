# Visión del producto

| Campo | Valor |
|---|---|
| Cliente | Bugalú Studio — estudio de producción y grabación musical |
| Producto | ERP web estandarizado para la operación del estudio |
| Alcance | Ver [alcance](alcance.md) |

Estandarizar el ciclo de servicio del estudio —contratación, producción, posproducción y cierre— en una sola plataforma web, desde la cotización hasta la descarga del máster.

El ciclo completo está en [flujos/ciclo-servicio.md](../02-dominio/flujos/ciclo-servicio.md).
